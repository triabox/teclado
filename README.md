# Teclado Anti-Stress

Teclado completo de teclas transparentes con sonidos de fluidos (burbujas, gotas, slime, gelatina, miel, lava…), modo realista 3D, luz RGB y pantalla completa.

Es una sola página estática (`index.html`), sin dependencias: los sonidos se generan con Web Audio.

Para correrlo local:

```bash
python3 -m http.server 8080
```
